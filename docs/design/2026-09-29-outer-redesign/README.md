# NekoFin 外层界面概念设计

第一轮视觉提案，使用内置 ImageGen 生成。用于评审布局与视觉方向，不是运行截图或最终交互规格。

## 范围

服务器选择、添加与登录、服务器配置、跨服务器搜索、设置、转码、弹幕、缓存，以及空状态和连接失败状态。服务器内部首页及内容浏览、详情和播放器不在本轮设计范围。未修改应用代码。

## 设计方向：私人放映室

- 暖白 `#F4F1EB`、墨黑 `#202320`、朱红 `#D74732`。深色模式采用 `#171B19` 底色和 `#ED705D` 强调色。
- 标题、留白与细分隔线建立层级，减少重复小卡片。服务器入口使用电影感封面；搜索使用纵向海报列表，保留来源信息。
- 底部保留服务器、搜索、设置三个主入口；添加服务器分为地址与账号两步。
- 设置按观影体验、外观、存储与关于分组。弹幕效果预览、主题预览为本轮提出的设计交互。

## 设计稿

1. `01-connection.png`：服务器选择、添加服务器、登录。
2. `02-search-settings.png`：聚合搜索、浅色设置、深色设置。
3. `03-preferences.png`：服务器配置、弹幕设置、缓存管理。
4. `04-states.png`：转码设置、首次使用、连接失败。

## 评审边界

图中服务器名称、媒体、容量、账号与地址均为演示内容，未访问真实服务器。图标与小字可能存在生成偏差，品牌标志只是探索方向。各图设备边框差异不属于产品设计。

设置图展示首屏层级，不意味着删减已有设置：弹幕速度、密度、偏移、来源和类型等保留在后续滚动区域；缓存分类仍需保留现有细分清理入口。实际落地需校准控件数值、完整状态、文字对比度、动态字体和触控区域。
