# Sideloading artwork

`download-on-livecontainer.svg` is a NekoFin source badge inspired by the layout of the [official AltStore download badge](https://faq.altstore.io/developers/download-on-altstore-badge). The AltStore logo is not included in this badge.

The LiveContainer icon is embedded unchanged from [`LiveContainer/LiveContainer`, revision `9108ae624ea001f7d7696d48407f890b48fa2653`](https://github.com/LiveContainer/LiveContainer/blob/9108ae624ea001f7d7696d48407f890b48fa2653/screenshots/livecontainer_icon.png). Credit belongs to the LiveContainer contributors. The icon and this composite badge retain the upstream AGPL-3.0 license; a copy is provided in `LICENSE-LiveContainer.txt`. The SVG is the editable source for the badge.

The READMEs display AltStore's official badge directly from the pinned upstream FAQ asset. It is not modified or rebranded.
